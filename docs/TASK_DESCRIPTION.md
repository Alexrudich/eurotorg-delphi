# Тестовое задание: Приложение «Складской учёт»

**Стек:** Embarcadero Delphi RAD Studio 13.1 | MS SQL Server Express (2022/2025) | FireDAC | FMX

**Автор:** соискатель на позицию «Инженер-программист Delphi и MS SQL»

---

## I.1. Задача

Разработать простое приложение на технологическом стеке:

- **Embarcadero Delphi RAD Studio 13.1**
- **СУБД MS SQL Express 2022** (по факту допускается 2025 — Express-редакция)
- Подключение к БД через компоненты **FireDAC**
- Интерфейс пользователя — стандартные компоненты на **FMX**
- Посторонние библиотеки компонент, не входящие в поставку RAD Studio, **не использовать**

Приложение должно позволять вести простой **складской количественно-суммовой учёт** в разрезе **партий** и **мест хранения** на складах.

## I.3. Что проектируется самостоятельно

- Таблица **Партий** проектируется самостоятельно.
- **Механизм учёта и расчёта остатков** проектируется самостоятельно.

## I.4. Документы для операций

1. Приход
2. Перемещение
3. Расход

## I.5. Требования к логике

- Списание партий по **FIFO** и **вручную**.
- Остатки должны быть **на Дату и Время**.
- Отчёт об остатках товара на определённый день и время отобразить в **TGrid**.
- **Код реализации должен быть простой и эффективный.**
